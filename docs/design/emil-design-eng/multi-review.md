# 多视角审计、修复与交付 · 2026-09-08—09

目标：使用 emil-design-eng，以独立审计视角复查当前全站设计与功能，复现实际缺陷，修复后完成浏览器回归和生产构建。

## 分工与验收

- 视觉与动效：独立子代理检查输入方式、动效中断、减少动态效果及视觉一致性。
- 功能连续性：独立子代理检查检索、URL、历史、列表与详情返回。
- 可访问性与媒体：独立子代理检查灯箱、焦点、原生媒体控制及错误恢复。
- 集成验收：主代理复现、筛选实际问题、实施修复并做浏览器回归；保留既有页面职责及零动画库约束。

审计结论必须使用 Before / After / Why 表，并区分代码推断、浏览器复现与已验证修复。不以意见数量作为验收标准，不额外引入产品功能。完成条件为已确认问题全部修复、相关检查通过并记录未覆盖的范围。

## 结果

三个独立子代理完成只读审计，交叉去重后确认5项问题；分别修复各自负责的文件，由主代理集成并完成回归。当前没有遗留的已确认代码问题。

| Before | After | Why |
| --- | --- | --- |
| 详情用布尔browse标记读取可覆盖的会话记录 | 链接携带实际cat/theme/q，详情从目录重建筛选顺序；位置记忆按筛选隔离 | 旧链接、新标签与不同筛选不互相覆盖 |
| 所有媒体统一按视口高度缩小 | 普通图片使用内容区完整宽度，只有视频按剩余视口适配 | 恢复图片宽屏阅读，保留视频原生控制空间 |
| 键盘打开灯箱后鼠标关闭仍使用instant，隐藏后等待220ms释放 | 每次关闭按当次输入计算；鼠标140ms，键盘立即释放 | 不出现不可见遮罩阻挡后续操作 |
| 灯箱只拦第二次pointerdown，move/up/cancel不识别指针 | 保存并校验pointerId，结束时释放对应捕获 | 第二根手指不能结束或移动第一根手指的手势 |
| 减少动态效果下，canplay打断用户主动视频播放 | 区分用户播放／暂停与程序自动播放／暂停 | 保留减少自动运动和原生手动控制两种意图 |

- 全站 `pnpm lint`、`pnpm --filter @personal-design/web typecheck`、`git diff --check`通过。

- `pnpm build`通过，525个静态页面。所有内容复用已审计页面模板，没有宣称逐条人工审核520条作品。
- 真实浏览器：黄金筛选进入002，随后进入另一套全量上下文，再重访原URL，仍返回黄金筛选，上一件禁用，下一件为003；另建标签直接打开该URL同样成立。历史隔离的纯逻辑回归也通过。
- 真实浏览器：灵感列表24→48自动追加；从1440px滚动位置进入作品后返回，恢复48件、1440px与来源焦点。
- 真实浏览器：1280×720时，图片使用1104px内容宽度、约933px自然高度；同一视口视频底部在656px，原生控制可达。亮暗主题截图复核。
- 真实浏览器：键盘开灯箱后鼠标关，修复前即时状态为transition:none但dialog和滚动锁仍存在；修复后为140ms过渡，随后正常卸载解锁。
- 真实浏览器：减少动态效果开启时视频默认暂停；主动播放、拖动到约5.59s进入readyState=1，缓冲完成至readyState=4仍继续播放；手动暂停后关闭减少动态效果仍保持暂停。子代理对实际视频处理器的异步事件模拟8项断言也通过。
