# V2 布局参考：从流动展示到可检索图鉴

状态：重新设计已实现；文件级 lint 通过；16项新浏览器流程场景通过，视觉由主任务统一采集与评审。旧 G4 双行浏览验收仅保留作历史记录，不用于 V2 结论。

## 用户任务与替换决定

| 用户任务 | 上一版成本 | V2 流程与归属 | 能力去向 |
| --- | --- | --- | --- |
| 查找构图或编号 | 双行持续移动，只能分类；8 个缺图条目无法发现 | LayoutWall 静态 5/4/2 列图鉴；分类、主题、关键词组合；名称/编号/分类/主题匹配 | 全部 350 条、8 缺图条目均有名称及直达详情链接 |
| 比较几张版式 | 双向流动不断改变阅读位置 | 规则肖像网格、无自动动画、稳定编号与名称 | 自动浏览与暂停控件删除，原生垂直阅读替代 |
| 读一张图鉴 | 卡片先打开灯箱，再找详情入口 | 所有卡片使用一个原生 Link 直接详情；仅详情图片支持放大 | 灯箱保留为阅读辅助工具，减少一次中转 |
| 理解详情与下一步 | 标题在媒体右侧窄面板，手机位于大图之后 | 返回/相邻导航 → 名称、分类主题 → 自然尺寸图 → 原图操作 → 同主题推荐 | 高清原图、放大、主题与前后项保留；无全高媒体井或右侧面板 |
| 返回继续浏览 | 分类链接无法完整保留关键词和阅读位置 | 列表点击存 URL/scrollY/卡片 id；返回图鉴恢复原 URL、滚动及焦点；直接进入详情回完整图鉴 | 浏览器原生历史继续有效；存储不可用回确定的列表路径 |
| 遇到缺图或无结果 | 缺图从列表隐藏 | 缺图卡无虚构媒体，名称/主题可读；详情说明图片缺失，保留主题恢复入口；无结果保留查询与清除 | 错误或缺失不会制造假放大/下载按钮 |

## 页面职责与源规则

- 按 contract.md Operate（检索比较）→ Read（图鉴阅读）的任务分工；轻量全站品牌由主任务负责，本页没有新增产品菜单。
- OpenDesign 中性实色 tokens、Albert Sans、中文零字距；详情 32/26px 与 1.35 行高，名称正文 14px，编号与尺寸 mono 12px。列表主标题使用共享 PageHeading。
- 容器 max1440、桌面48/平板24/手机20px；静态网格桌面5列、1024px4列、手机2列。媒体8px圆角，无整卡嵌套框线。
- 普通操作复用共享 Button；搜索/主题原生 input/select，边界用 control-border，placeholder 显式 opacity1；Search 提交按钮不压缩换行。
- 没有列表动画或整页入场；详情高清交替沿用有界状态反馈，reduced-motion 不影响任何内容可达性。
- 本地 Next Link/useSearchParams 文档已核对：列表查询组件位于 Suspense，URL 驱动筛选；链接保留原生导航语义。所有内容仍来自内容包 API，未改数据/纠正映射/生成图片。
