# V2 体验与页面设计契约

用户否定上一版，允许全部UI/UX调整。本轮code-led，OpenDesign色板/Albert/控件/排印是语言，旧布局不是约束。完整目标见 docs/goals/ui-ux-redesign-v2.md。

## 问题与决策

1. 仅三项导航却固定占216px并套全高面板，重复品牌说明。用户进一步确认：彻底取消全站菜单导航，首页即产品菜单。内页只留上下文返回入口，内容区域获得完整横向空间。
2. 首页把两个产品藏在横滑轨道，用户必须理解节点、进度和下一页。改为并排的两个内容入口，在首屏同时看见用途与真实内容，手机自然纵读；保留关于和署名，移除虚构未来操作。
3. 列表图片打开灯箱、视频打开详情、标题再开详情，去向不可预期。统一原生链接直达详情；详情内才提供放大/完整查看。移除自动滚动和被动追加，保留明确追加按钮与返回现场。
4. 图鉴是可查找知识库，自动移动双行不适合比较。改为静态响应网格，分类+主题+关键词可查，缺图条目也能搜索并进入说明。
5. 详情的标题在窄侧栏，数据和主操作重叠争夺层级，固定媒体井造成空白。改为标题/作者/返回在媒体之前，媒体根据比例且有上限自然展示，底部来源/资料与前后内容。不得固定一大块视口空井。

## 全站空间与组件

主任务拥有WorkspaceShell/PageHeading/CategoryTabs/global/Button和404；无侧栏，也无全站产品菜单。顶部仅轻量品牌/返回首页链接与主题开关，最终实现一行88px；手机一行72px。首页承担产品导航，内页通过返回列表/首页及上下条目完成任务。主体max-width1440px，页内水平48px desktop/24px tablet/20px mobile。主页可max1280px。页面专属容器不再叠加shell padding。轻量页头自然文档流，不设置重复菜单。

标题：列表36px desktop/28mobile，主副文本清楚分组；详情32/26，首页可48/34。中文tracking0，标题1.35。body14/1.75，主介绍16px。辅助12px只用于辅助数据。色板不改，实色面板，4px普通控件、主按钮pill、8/12媒体圆角，避免面板套面板。将边框留给输入/分组边界，不能每段都做卡片。

PageHeading现有API兼容。CategoryTabs现有API兼容，改为简洁下划线选择、手机横滑单行（可见溢出提示/原生可达）。Button现有API不变。各产品筛选主工具条：关键词输入稳定位置，分类导航与结果信息分组，不重复总数和过量日期。

## 页面方案 / 首屏

- 首页：清晰短标题“设计，随手可查。”（产品事实描述，不加宣传数值）；两个产品真实媒体入口首屏并列，灵感场景图与图鉴内容形成对照，标题/用途/进入一组。下方轻量关于与来源。
- 灵感列表：标题与说明，检索工具，4列desktop/3tablet/2或1mobile按阅读尺寸；规则对齐的媒体框object-contain，统一直接链接，标题和作者位于媒体下面，不整卡多层描边。允许预览静音video但必须尊重RM并可暂停（简单全局开关或仅主动悬停），默认静态poster更安静。
- 灵感详情：顶部返回与邻项导航，作品标题/作者/分类，媒体主舞台，适用的缩略图/页数明确；来源、描述与原始JSON在下方，直接页面没有多余breadcrumb长链。手机标题在媒体之前。
- 布局列表：先可找到，再可比较；分类、主题、关键词；静态portrait网格desktop5或6/tablet4/mobile2。单卡点击直进详情。缺图卡维持名称与主题，无伪造图片。
- 布局详情：返回/上一张下一张；名称和分类主题；可读尺寸大图，原图/放大是媒体操作；真实说明与同主题推荐在下方；无全高右侧嵌套面板。

## 交互与状态

统一卡片直接链接的签名体验是“不中断的浏览”：进入详情、查看媒体与出处、返回原筛选和位置。焦点和URL都保留；避免先灯箱再详情的中转。灯箱仅是详情内的放大工具。所有原有内容能力保留但旧操作形态可删除；相应测试要重新按任务结果写，不能用旧点击步骤绑架新UI。

视频保留原生控制；列表默认安静，详情主动播放。分页/媒体控制边界明确；失败有有界等待和恢复；无效筛选可重置。普通路由不添加假loading。减少动态效果下所有内容与操作可达。

## 所有权与并行

root: shell/category/header/global/404/contract/integration。
home: 首页/home-view及局部CSS，可通过数据包API取得媒体，products.ts仅事实必要调整。
muse: muse所有路由/plate-wall/carousel/return-link及局部CSS。
layouts: layout路由/layout-wall/detail-tools及局部CSS。
shared: 此阶段不改共享灯箱；root协调需要的接口。

各任务先读相关Next本地文档和源规范，实现完整页面与状态，自己的新行为脚本写 scripts/design-checks/v2-<module>.mjs，报告 docs/design/redesign-v2/<module>.md。不改其他任务文件，不复制旧测试结果。现有页面形态保留约束被本轮用户授权覆盖。
