# V2 全局入口、控件与恢复路径

## 页面职责

首页是唯一产品菜单。全站固定侧栏、产品菜单、重复产品入口和长品牌说明已移除；页头只有品牌首页链接与主题开关。内页使用自己的返回列表/上一项/下一项，不在页头增加菜单。404说明地址无内容，仅提供返回首页重新选择。

分类属于当前内容筛选，改为单行下划线按钮组。手机原生横向滚动、键盘聚焦自动进入可见区域；它没有冒充页级菜单或ARIA tab面板。主内容导航使用原生链接，列表媒体/标题统一同一入口。

同步导航和主题按钮不制造loading/error；媒体等待由真实媒体层负责。共享灯箱内部成熟的焦点、退出和滚动锁机制保留，入口职责在本轮重设计；旧独立测试不冒充本轮通过，本轮两种详情实际重新打开/关闭验证。

## 本轮结果与范围

生产 Chromium 的18项基础断言和两条跨产品完整旅程通过。验证320px与720pxCSS布局宽度；720px是1440px在200%下的等效重排宽度，不宣称真实桌面缩放操作。主题存储失败、无效存储、系统动态偏好和跨标签同步均已执行。按钮视觉由集中截图和独立复核补充，不从测试通过推导审美质量。

独立复核要求的视频尺寸修正已落地：视频按标题、导航之后的剩余可视高度设置最大尺寸并保留工具栏空间；只响应布局/窗口/字体变化，普通滚动不缩放。原生控制及工具栏在1440×900、1024×768、390×844首屏实际可见，见evidence/video-viewport.json。404删除了独立的状态码上标，仅保留标题、解释和首页入口。
