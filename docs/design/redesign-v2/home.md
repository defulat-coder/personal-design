# V2 首页：选择要查找的内容

状态：新页面及行为验证完成，视觉复核等待主任务统一截图。本记录不沿用 V1 的设计认可或旧截图。

## 用户目的、问题与新流程

| 用户目的 | 旧界面成本 | V2 入口与行为 | 结果 |
| --- | --- | --- | --- |
| 判断该进入哪个产品 | 上线日期、节点与轨道抢占首层；两项产品需要横向手势；未来节点无实际目的 | 首屏同时并列布局参考与灵感集，用真实内容、用途和进入提示区分；整组只有一个原生链接 | 桌面两项完整入口同时可见，手机自然纵读 |
| 进入内容 | 封面/标题与额外进入按钮重复，且拖动需要抑制误触 | 每个产品只有一个可聚焦链接，覆盖预览与文字；Enter 与点击直接进入列表 | 没有轨道模式、拖动、进度控件或重复按钮 |
| 了解站点与许可 | 关于内容位于轨道后段 | 产品之后的轻量文字区，介绍与图鉴许可并列 | 来源常量、外链与 CC BY 保留，删除虚构未来节点 |

最新用户要求：首页本身就是全站产品菜单，没有额外全局产品菜单。页面入口采用完整产品名称和明确去向，不增加导航或侧栏。

## 构图与实现

- 自然文档流，主区 max-width 1280px；桌面内边距 48px，平板 24px，手机 20px。不依赖 workspace 高度或锁定滚动。
- 标题“设计，随手可查。”为 48px / 1.35、手机 34px；无 eyebrow、统计英雄区或广告承诺。短说明将任务分为查构图与找灵感。
- 桌面两个平行内容入口，40px 间隔。布局参考展示三个分类中的真实图鉴缩略图，灵感集展示注册表中的真实设计场景。图像之外没有逐层套框。26px 产品标题、16px 用途、14px 描述、12px 辅助数据建立层次。
- 布局预览由服务端 `catalog` / `categories` / `hasImage` / `thumbnailUrl` API 取得，不拼媒体路径、不改内容包；灵感预览沿用产品注册表已有图。
- 中性源 tokens、Albert Sans、中文 tracking 0、12px 媒体圆角；hover 仅将进入箭头轻移 2px，reduced-motion 关闭位移。焦点环明确覆盖整个入口。
- 首页不再导入 LifelineTimeline。旧时间轴组件和 V1 行为脚本是历史实现，由主任务在清理未使用文件时统一处置。
