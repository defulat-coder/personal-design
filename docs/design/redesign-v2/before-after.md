# 用户任务的改版前后对照

这份对照描述已实现的方案差异；行为验证见本轮evidence与模块报告，视觉及UX修正评分见finish-review.md。基准截图包括 `.impeccable/review/redesign-v2/before-detail.png`，以及上一轮 full-design 的实际捕获；旧ship不作为本轮成功证据。

| 用户任务 | 原体验问题 | 本轮改变 | 结果如何验证 |
| --- | --- | --- | --- |
| 选择产品 | 首页横滑轨道及全站菜单重复承担导航，只有两个产品仍需理解节点/进度 | 首页两个内容入口同时出现；全站取消菜单，内页品牌只作为首页出口 | 首页首屏入口可见、全站无产品菜单、原生链接直达 |
| 找一件灵感 | 图片点开灯箱、视频点开详情、标题又是另一个入口 | 一件内容一个详情链接，静态预览，统一行为 | 图片、视频、多媒体各一次点击进入对应详情 |
| 稳定浏览 | 不同高低瀑布阅读顺序不明确，自动加载改变页面长度 | 对齐媒体框的网格、明确追加按钮 | 视觉扫描顺序及追加/返回保留位置 |
| 找一种构图 | 两行图鉴自行移动，难停留比较；只显示有图条目 | 静态网格，分类/主题/关键词查找，缺图条目保留 | 搜索、组合筛选、缺图可达、无自动位移 |
| 理解正在看的作品 | 标题和作者在媒体旁窄栏，手机须先翻过大媒体区 | 标题/作者/返回在媒体前，媒体自然比例，资料按阅读顺序在下 | 桌面及手机视觉顺序、长标题、多种比例 |
| 深入看媒体 | 列表预览和详情重复中转，媒体井按视口撑高 | 直接进入详情，放大作为详情内工具；原生视频主动播放 | 放大关闭返回焦点，视频原生控制，多媒体切换 |
| 查看来源 | 来源动作与普通数据在侧栏拥挤 | 独立清楚的来源区域和原始JSON，资料渐进展开 | 原始链接真实、JSON可读、Esc不误导航 |
| 返回继续 | 多入口可能回到默认列表，需重新定位 | 保存筛选、已显示数量/位置，返回原列表 | 两条跨模块完整旅程，键盘焦点与位置检查 |
| 出错后继续 | 各表面虽有错误反馈但整体恢复路径缺少设计 | 保留有界媒体恢复、查询条件、缺图说明；404回首页重新选择 | 主动注入媒体错误/延迟、空结果、无效URL |

本轮不添加收藏、账户或下载成功等未实现承诺。原资源在外站打开的动作以真实语义呈现。产品能力保留，原始结构可替换。
