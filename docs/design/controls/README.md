# 全局控件设计 · 2026-09-11

以统一的圆形／胶囊操作、细线图标和中性层级连接首页、书架、灵感集与独立详情。使用 impeccable（extract／polish）与 emil-design-eng；本轮沿用已有页面结构。

## 盘点与调整

| 范围 | 原有问题 | 统一方案与实现 |
| --- | --- | --- |
| 基础按钮、错误恢复、404 | 普通方角、专用圆形和裸按钮并存 | Button／buttonClassName：主动作实心、次动作描边、返回与清除透明 |
| 页头／主题 | 返回方向与站内进入不对应，主题另有尺寸规则 | 向左返回，主题复用44px圆形图标按钮 |
| 首页时间轴 | 时间轴箭头与其他翻页样式不同 | 溢出时显示共享圆形翻页按钮；站内入口向右、外链向右上 |
| 两个集合搜索 | 即时搜索仍有展开和提交操作 | 常驻44px输入框，输入即过滤；有词才显示清除，支持 `/` 聚焦 |
| 分类 | 分类、搜索高度与线条节奏不一 | 44px目标，选中1px下划线，数量集中在结果区 |
| 书架／画册 | 翻页存在独立按钮样式 | 左右中部共享圆形按钮；书页点击放大，无详情跳转 |
| 搜索命中项 | 站内进入使用外链箭头 | 向右箭头，打开所属分类及命中跨页 |
| 独立详情 | 返回与连续浏览同等视觉重量 | 返回透明，上一件／下一件描边；保留筛选上下文 |
| 多媒体轮播 | 翻图在底部与来源入口混排 | 前后按钮移到媒体左右中部；底部留计数与来源 |
| 灯箱 | 独立控件颜色与线条规则 | 复用共享按钮，局部深色语义主题，关闭与焦点回归保留 |
| 个人网站 | 页头与正文重复返回首页 | 保留页头返回、正文唯一主要外链操作 |

## 共享契约

- 操作高度44px；文字14px／500，行高22px，水平内边距18px；图标18px，线宽1.6px。
- 文字操作胶囊、图标操作圆形。默认细边框；透明返回承担较低层级；主动作使用 ink／paper。
- Hover只用于精细指针；方向箭头移动2px，按下缩至0.96；键盘和减少动态效果取消空间动画。
- 焦点环2px、外偏3px。禁用使用原生语义；所有无文字操作有可访问名称。
- 搜索无提交步骤；Esc退出输入焦点但保留查询，清除后焦点留在输入框。
- 原生链接保留链接语义。正文链接、实体书脊、图片放大提示、原生视频控制不强制改为按钮。
- 全局 tokens 留在 globals.css，组件状态与几何归相邻 CSS Module；不新增控件库或动画依赖。

## 验证

类型检查、全站 lint、生产构建（526个静态页面）与10项浏览上下文测试通过。浏览器检查覆盖1280px首页、灵感列表、筛选内相邻浏览与返回、深色详情、书页放大及Esc焦点回归、多媒体从1/4切换到2/4、个人网站主要操作；390px灵感列表搜索完整可用且页面无横向溢出。

设计检测已执行一次。唯一主要提示是实体书架的8px底板边界，属于用户指定实体书造型；书纸色、装订阴影与缩略预览小字提示也归此局部表面，不扩展到全局控件。未声明逐一验证526条内容、全部浏览器或每种网络失败。

## 后续修正：搜索与画册层级

用户反馈胶囊搜索与开放页面不搭、画册有上下两层退出。本轮改为无填充的240px底线输入，清除仅有词时出现，去掉快捷键装饰；检索仍即时可用。画册页头临时承担返回书架，正文不再重复返回按钮，书架页头再返回首页；借此删除一整行导航并扩大书页。该条覆盖上方搜索胶囊与独立书架返回的历史实现。

本次修正验证：1280px搜索即时命中8项、清除可用；画册页头返回后焦点恢复至对应书脊；390px深色搜索无横向溢出。类型检查、lint、构建与10项浏览测试通过。搜索及页头定向设计扫描无主要提示。
